# 🌾 AI Powered Crop Yield Prediction

An AI-powered web application that predicts crop yield based on environmental and agricultural factors using Machine Learning.

Live Demo
https://ai-powered-crop-yield-prediction-and-zfjl.onrender.com/

## 📌 Project Overview

This project helps farmers and agricultural researchers estimate crop yield by entering:

- Rainfall (mm)
- Temperature (°C)
- Humidity (%)
- Area (Acres)

The prediction is generated using a trained Machine Learning model and displayed through a simple Flask web application.

## 🚀 Features

- Predict crop yield instantly

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/preethigovindasamy2007-design/AI-POWERED-CROP-YIELD-PREDICTION.git
```

Move into the project folder:

```bash
cd AI-POWERED-CROP-YIELD-PREDICTION
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
